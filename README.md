# Dotfront — Swarm Command

A minimalist browser RTS and installable offline-capable Progressive Web App for desktop, Android and iPhone.

The playable game lives at `index.html`. To publish via GitHub Pages, go to **Settings → Pages**, select **Deploy from a branch**, `main`, `/ (root)`.

Mobile: install from the browser's home-screen menu after deployment. Progress is stored locally; use in-game export to back it up.
